# 依赖清单

本仓库只包含自制源码。要让服务器完整运行，还需要以下内容。
所有路径均相对于服务器的 `garrysmod/` 根目录。

## 二、二进制模块（`lua/bin/`）

放入 `garrysmod/lua/bin/`，文件名必须严格保持 `gmsv_<模块>_<平台>.dll` 格式（`linux` / `linux64` / `win32` / `win64`），否则加载不到。

| 模块 | 用途 | 官方来源 |
|---|---|---|
| `gwsockets` | WebSocket 客户端 | [viral32111/GWSockets](https://github.com/viral32111/GWSockets)（原 [FredyH/GWSockets](https://github.com/FredyH/GWSockets)） |
| `mysqloo` | MySQL / MariaDB 连接 | [FredyH/MySQLOO](https://github.com/FredyH/MySQLOO/releases) |
| `chttp` | 可换 User-Agent 的 HTTP（curl 封装） | [timschumi/gmod-chttp](https://github.com/timschumi/gmod-chttp) |
| `reqwest` | HTTP 替换模块（Rust 实现） | [WilliamVenner/gmsv_reqwest](https://github.com/WilliamVenner/gmsv_reqwest) |
| `enginespew` | 捕获引擎 / Lua 日志推回 Lua 层 | [Metastruct/gm_enginespew](https://github.com/Metastruct/gm_enginespew) |
| `sourcenet` | 引擎底层接口扩展 | [danielga/gm_sourcenet](https://github.com/danielga/gm_sourcenet) |

> 本适配包中这些 DLL 的构建日期为 **2025-02-27**，请按服务器实际架构（32 位 / 64 位；Linux / Windows）从官方仓库 Releases 下载对应版本。

> ⚠️ **社区报告**：2026 年 4 月的 GMod 更新后，有服务器因 `sourcenet`、`serversecure` 等二进制模块出现玩家进服卡死（`NetworkIDValidated` 之后无法创建玩家实体），Facepunch 官方在 issue 中建议删除此类模块或向模块作者索取更新版本（[Facepunch/garrysmod-issues#6833](https://github.com/Facepunch/garrysmod-issues/issues/6833)）。若服务器实际不依赖 `sourcenet`，建议移除。

## 三、运行状态（`data/`）

服务器运行时会自动生成（ULX 分组 / 用户、日志、记事本等），**不需要**手动准备。

需要手动获取的可选内容（完整服务端包中提供，本仓库不含）：

- `data/breach/scp.txt` —— SCP 数值自定义（INI 格式，改完重启生效）
- `data/data_scp263/` —— SCP-263 问答题库（`en_questions.json` / `fr_questions.json`）
