     限制：仅超级管理员可用；核弹倒计时期间拒绝执行（与原有规则一致）；
           每次执行在服务器控制台打印触发者。

51.【根因修复】sv_player_data.lua — StoredData 为 nil
     问题：UpdateData 的异步 onSuccess 回调直接索引 ply.StoredData，
           但在 PlayerInitialSpawn 阶段 LoadPlayer 还没建好该表，
           报 "attempt to index field 'StoredData' (a nil value)"。
     修复：回调内加 ply.StoredData = ply.StoredData or {} 兜底；
           同时把永久 VIP 的写库延后到玩家数据加载完成之后，避免竞态。

52.【根因修复】sh_module.lua — GetRoleName 为 nil
     问题：SetupMove 钩子里写的是 pl:GetRoleName()，而 pl 是 ply:GetTable()
           返回的普通表，GetRoleName 是 Player 元表上的 NetworkVar 访问器，
           不在该表上，每次移动都报错，SetupMove 后续逻辑全部失效。
     修复：改为 ply:GetRoleName()，并在 NetworkVar 尚未注册时提前返回。

53.【根因修复】cl_module.lua — 心跳音效使用 NULL 实体
     问题：HeartbeatSound 定时器在地图切换/重连期间也会触发，此时
           LocalPlayer() 是 NULL。原来的 LocalPlayer().Alive 检查能过，
           紧接着调 :Alive() 就报 "Tried to use a NULL entity!"。
     修复：先取局部变量并做 IsValid 判断。

54.【回归修复】进服观察者仍有实体、能走能跑、能被 sslay
     问题：上一版的校正定时器首次触发要等 0.5 秒，这段窗口内玩家是活人；
           且只设了 SetNotSolid，引擎仍会做玩家 hull 的世界碰撞，所以穿不了墙。
     修复：ForceSpectator 提为全局 RXSEND_ForceSpectator 并追加
           SetSolid(SOLID_NONE)；进服时立即执行一次，不再等定时器；
           校正频率改为每 0.1 秒共 6 秒；改用 RXSEND_PendingSpectator 标记，
           PlayerSpawn 期间无条件压回观察态，直到 SetupNormal 真正分配角色时解锁。
     配套：SetupNormal 里复位 SetSolid(SOLID_BBOX) / SetNotSolid(false) /
           COLLISION_GROUP_PLAYER，否则真正出生后玩家能穿墙且不吃子弹。

55.【根因修复】枪打不死原生 bot
     问题：GM:ScalePlayerDamage 中有三处会抛错并中断整个函数，
           伤害缩放因此全部丢失，表现为"打不死"：
             a) hitpos 表里 ply:GetSequenceActivity(ply:LookupSequence("flinch_01"))
                —— bot 用的默认模型没有 flinch_* 动作，LookupSequence 返回 -1，
                GetSequenceActivity(-1) 必崩；
             b) SCP096 分支直接索引 ply:GetActiveWeapon().victims，
                对没跑过 ApplyRoleStats 的 bot，武器为 NULL 或没有 victims；
             c) 攻击者带 NoDamage 时调用了一个根本不存在的全局函数
                （原作者留下的俄文脏话占位符）。
     修复：a) 加 SafeSeqAct 包装，动作不存在时返回 nil；
           b) 补 IsValid + istable 前置判断；
           c) 删除该无效调用，并在函数开头加 ply 有效性检查。

56.【根因修复】A门停机坪飞机、C门装甲车不来
     问题：EvacuationWarhead 里引用的全局 apc / heli 从来没有被创建过

             b) 直升机撤离结算里调用了从未定义的 goose_plz_fuck_off_heli()。
