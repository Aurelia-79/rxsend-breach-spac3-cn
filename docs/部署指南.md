# RXSEND SCP 国服适配 — 服务器部署指南

本包由以下部分拼合而成：
- 安全清理 + 全中文汉化的 `rxsend_breach` 游戏模式（源码仓库 `rxsend_breach-main`）
- 国服 Workshop 全部 40 个内容 GMA 解包后的文件（直接放进 `addons/`，无需再订阅 Workshop）
- 3 个适配 addon（`_adapter_models` / `_adapter_sounds` / `_adapter_materials`），把代码引用的路径对到国服包里的实际文件

---

## 一、内容包结构（rxsend_server_content/）

```
addons/                       ← 40 个 Workshop 内容 + 21 个仓库自带 addon + 3 个适配 addon
  _adapter_models/            模型适配：代码期望的 models/... 路径 → 国服实际模型
  _adapter_sounds/            声音适配：代码期望的 sound/... 路径 → 国服实际音效
  _adapter_materials/         材质适配：代码期望的 materials/... 路径 → 国服实际贴图
  3168732387/                 主地图 cn_rxsend_site19_demo.bsp（92MB）

lua/                          仓库自带模块（chttp/gwsockets 等）
data/                         ULX/ULib 数据、SCP-263 问答等
_*.py / _*.txt                适配过程用的脚本与映射表（可删除）
```

### 适配统计
- **模型**：gamemode 618 处引用 → 585 精确命中 + 1 基名命中 + 32 缺失（全部为 GMod/HL2/CS:S 基础模型，服务器自带）
- **声音**：399 处引用 → 86 条映射已应用（含 049-2 僵尸、防毒面具、核弹序列、电台、BGM 等）；剩余缺失均为国服未打进 Workshop 的自定义曲目，静音但不报错
- **材质**：246 处引用 → 28 条映射已应用；剩余为引擎/游戏自带或 `CreateMaterial` 动态生成
- **地图**：`cn_rxsend_site19_demo` mapconfig 已创建（复制自 rxsend_site19.lua），与国服地图名一致
- **安全**：全部 147 个包内 Lua 文件已扫描，无后门/无 RCE；仓库侧已移除 CW20 RCE 与 LeyHitreg 后门
- **稳定性**：已删除 2 组完全重复的内容 addon（3788795433≈3074010797、3788791186≈3074027601）
  和 2 个旧地图 addon（3788784337、3074052619，其地图无 mapconfig 无法使用）。
  **重要：GMod 服务端文件总数超过约 66,000 时会在启动阶段崩溃（表现为 steam.dll 访问冲突）。
  本包已精简至约 62,000 文件；以后往服务器加内容时请留意总数，不要再超过 65,000。**

## 二、全新服务器安装（SteamCMD）

```bat
steamcmd +login anonymous +force_install_dir D:\gmod_server +app_update 4020 validate +quit
```

- `4020` = Garry's Mod 专用服务器。装完在 `D:\gmod_server\garrysmod\` 下。
- 本适配包已包含全部国服 Workshop 内容（已解包为普通文件），**不需要** `+workshop_download_item`，也**不需要**在服务器上配置 workshop collection。

---

## 三、部署内容

把本包内的以下目录合并进服务器 `garrysmod/`：

```
rxsend_server_content/addons      →  garrysmod/addons
rxsend_server_content/gamemodes   →  garrysmod/gamemodes
rxsend_server_content/lua         →  garrysmod/lua
rxsend_server_content/data        →  garrysmod/data
```

> 注意：`addons` 下的目录名含方括号（如 `[weapons]_cw_20`），
> 用资源管理器或 robocopy 复制，别用会解析通配符的旧脚本。

## 四、启动命令

```
srcds.exe -game garrysmod -console -port 27015 +maxplayers 32 +gamemode rxsend_breach +map cn_rxsend_site19_demo +host_workshop_collection 3796043743 -authkey <你的Steam Web API Key>
```

参数说明：
- `+gamemode rxsend_breach` 指定游戏模式
- `+map cn_rxsend_site19_demo` 国服主图（BSP 已在 addons 内，直接加载）
- `+host_workshop_collection 3796043743` 挂载服务器专用工坊合集（玩家进服由 Steam 满速下载贴图模型）
- `-authkey <你的Steam Web API Key>` Steam Web API 授权码
- 想换图可参考 `gamemodes/rxsend_breach/gamemode/mapconfigs/` 下的其它 mapconfig

常用控制台命令（管理员，需先给自己加权限）：
```
ulx adduser 你的SteamID superadmin
ulx map cn_rxsend_site19_demo
changelevel cn_rxsend_site19_demo
```
